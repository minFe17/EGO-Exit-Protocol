# 🎮 EGO :: Exit Protocol

Unity로 개발한 **내러티브 어드벤처** 게임입니다.  
플레이어는 **반복되는 루프를 경험**하며 자신의 정체성과 진실을 깨닫고, 결국 탈출을 시도하게 됩니다.

- **플랫폼** : PC (Windows)
- **Unity 버전** : 6000.0.50f1
- **📄 기술문서 링크** : [기술문서 링크](https://drive.google.com/drive/folders/1gcQ5xP3MlVEgDHBIyB4wQR_PSS4JhcN1?hl=ko)
- **📒 개발 일지** : [개발 일지 노션 링크](https://mincheolstudy.notion.site/EGO-Exit-Protocol-224d4b6c965c80c6bd51f4ea671da840)

## 🎯 기술 목표

이 프로젝트는 다음과 같은 기술적 목표 및 학습을 중심으로 개발되었습니다:

- **루프 시스템 구현** 및 상태 초기화 처리
- **GPU 렌더 텍스처 캡처** 기능 구현
- 메멘토 패턴을 활용한 **상태 복원 시스템** 구현
- **중재자와 옵저버 패턴을 결합**한 이벤트 관리 구현
- **BFS 탐색 알고리즘**을 적용한 경로 탐색 기능 개발
- **Steamworks** 연동을 통한 Steam 출시 경험
